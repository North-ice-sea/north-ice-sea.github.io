Personal rclone Google Drive Setup

Project information maintained by North-ice-sea.

Personal-use configuration · Not a public hosted service

What this project does

This project documents a personal installation of rclone, an open-source command-line file management tool. The owner runs rclone on their own Ubuntu computer and authorizes it with Google OAuth to access their own Google Drive account.

The setup can mount a selected Google Drive folder on the owner's computer so local applications can read and write files there. The purpose is personal file access and exchange between the owner's local development tools and Google Drive.

How Google Drive data is used

When the owner runs rclone, Google OAuth asks the owner to grant the permissions shown on Google's consent screen. Depending on the granted permissions and the commands the owner runs, rclone can list, read, download, upload, update, or delete files in Google Drive. The configured Drive access is broad, so the owner should authorize it only for an account they control.

File transfers are initiated by the owner from their own computer and take place between that computer and Google Drive through Google's APIs. This GitHub Pages website does not receive or process the owner's Drive file contents.

Who can use it

This is a personal configuration for the repository owner. It is not a multi-user service, does not provide accounts to the public, and is not affiliated with or endorsed by Google.

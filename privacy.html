Privacy Policy

Personal rclone Google Drive Setup · Effective date: 14 November 2026

This policy describes the personal rclone configuration maintained by North-ice-sea. It is not a policy for the rclone project, Google, GitHub, or any separately connected application.

1. Scope and purpose

This configuration is for the repository owner's personal use. The owner runs rclone on their own computer and uses Google OAuth to access their own Google Drive account. It is not a public service and does not onboard or manage other users.

2. Google user data accessed

After the owner grants consent, rclone accesses Google Drive data through Google's APIs according to the OAuth scopes granted and the commands the owner runs. The configured permissions include broad Google Drive file access and read-only Drive metadata access. The OAuth consent configuration may also declare a Google Docs scope. The exact access available at runtime is determined by the scopes requested and approved by Google.

Depending on the owner's actions, rclone may access file names, folder structure, file metadata, and file contents, and may create, upload, download, update, or delete Drive files. The owner should review the permissions on Google's consent screen before authorizing access.

3. How data is used and transferred

Google Drive data is used only to carry out file listing, transfer, synchronization, and mounting operations explicitly initiated by the owner. Transfers occur between the owner's computer and Google Drive through Google's APIs.

This informational website does not collect Google Drive files, read Google account contents, or receive OAuth access tokens. The rclone configuration described here does not send Drive file contents to the website operator. If the owner separately connects Google Drive to another application, that application's own privacy policy and permissions apply.

4. Storage and retention

OAuth client configuration and authorization tokens are stored locally on the owner's computer in the rclone configuration file, normally ~/.config/rclone/rclone.conf. The owner is responsible for protecting that file and the computer account. rclone may also use a local cache directory when configured to do so.

Files uploaded to Google Drive remain in the owner's Google Drive account until the owner deletes them. Local copies and cache files remain on the owner's computer until the owner removes them. This website does not maintain a separate database of Drive data.

5. Sharing and service providers

Drive file data is transmitted to Google as necessary to use Google Drive APIs and is handled under Google's applicable terms and privacy policies. This website is hosted by GitHub Pages; GitHub may process technical request data under its own policies. The project operator does not sell Google user data or disclose it to data brokers or advertisers.

6. Security

The owner should keep OAuth client secrets and refresh tokens private, restrict local file permissions, avoid committing credentials to source control, and revoke access if a device or credential is compromised. No website or local configuration can guarantee absolute security.

7. Choices, revocation, and deletion

The owner can revoke this application's Google account access from their Google Account security settings. The owner can delete files from Google Drive and remove local files or rclone configuration data from their computer. Revoking OAuth access prevents future API access using the revoked grant; it does not automatically delete files already stored in Google Drive or local copies.

8. Changes to this policy

This policy will be updated if the personal configuration's data practices materially change. The effective date above indicates the latest revision.

9. Contact

For questions about this personal configuration, contact the repository owner through the North-ice-sea GitHub profile.
